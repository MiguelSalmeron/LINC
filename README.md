a mini game created with godot engine for Hackclub haven.

You can play the web demo on:
https://miguelsalmeron.itch.io/linc

# About the game
- controls: arrow keys /WASD to move, space to jump
- objetive: reach the goal 


# How to run locally
1. Download and install [Godot Engine 4](https://godotengine.org/)
2. clone this repository: \`\`\`bash
   git clone https://github.com/MiguelSalmeron/LINC.git
   \`\`\`
3. open godot engine and click "import"
4. select the \`project.godot\` file inside the cloned folder.
5. press the Play button in the top right to run the project.
